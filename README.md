# Aula_CI_CD
Gere um documento PDF contendo evidências (prints) da criação da sua conta Expo e do repositório no GitHub, configuração do EAS e configuração do CI/CD acionado pelo GitHub Actions.

Etapas: 

Criar conta no Expo (http://expo.dev/signup)
Criar um projeto Expo, nomeado como "SEUNOME_CI_CD"
Criar um repositório PÚBLICO no GitHub, nomeado como "Aula_CI_CD"
Clonar o repositório na máquina (pode ser em downloads) e excluir o README.md
Copiar/colar os arquivos do template da aula na raíz do repositório.
No Expo, vincular o projeto com sua conta do GitHub (print ao final)
Aplicar a parte "7. Automatizando o processo com GitHub Workflows" do livro "Guia: CI/CD - Aplicações Móveis"
Criar o diretório .eas/workflows
Configurar arquivo pipeline.yml
Realizar commit/push para acionar a pipeline
Tirar os prints do GitHub Actions e o Expo Workflow sendo executado para o relatório, junto da URL do repositório.
Relatório sugerido: 

Seu nome/RA;
URL do Repositório (PÚBLICO) criado no GitHub;
Imagem dos diretórios ".eas/workflows" e o arquivo "pipeline.yml" implementando o workflow no VSCode;
Imagem do Actions sendo disparado ao realizar o "push" na branch "main" do GitHub (clique na bolinha amarela para ver o status);
Imagem do workflow sendo executado no Expo (no GitHub, clique em 'details' que te redirecionará para o Expo);
